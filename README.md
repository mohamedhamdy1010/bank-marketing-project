# 🏦 Bank Marketing Prediction

A Machine Learning application built with **Streamlit** to predict whether a bank customer is likely to subscribe to a term deposit.

## 📌 Project Overview

The application uses customer information from a bank marketing campaign and applies a **Random Forest Classifier** to predict the customer's subscription decision.

## 🤖 Machine Learning

* Random Forest Classifier
* Train/Test Split
* Accuracy
* Precision
* Recall
* Confusion Matrix
* Feature Importance

## 🛠️ Technologies

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## 🚀 Run Locally

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run bank_marketing_app.py
```
